## Project 1 — HR Analytics Dashboard

### Overview

The HR Analytics project focused on understanding **employee attrition trends and workforce demographics**. The dashboard provided a data-driven view of how age, salary, education, gender, tenure, and job role influence attrition.

### Key Takeaways

- Identified age groups and job roles with highest attrition
- Observed trends in salary slab vs attrition
- Analyzed gender-wise attrition distribution
- Measured average employee income, age, tenure
- Built KPIs for overall attrition and headcount

This project strengthened my understanding of **HR metrics and workforce analytics**.

---

## Project 2 — Real Estate Market Analytics Dashboard

### Overview

The Real Estate Analytics project involved analyzing **property listings across cities and states**. The dashboard tracked market distribution of properties by price, status, listing agent and property type.

### Key Takeaways

- Built KPI indicators for sold, pending, and active properties
- Created price trend vs days-on-market analysis
- Compared property types (apartment, townhouse, single-family, multi-family)
- Designed agent-based property performance analysis
- Built market-status waterfall and donut visuals

This project improved my learning around **business dashboards and market analytics**.
